The worst superpower in one line: x-ray vision that only works through glass, and only when the glass is clean. Built by an AI agent for make.fun's “Worst Superpower” bounty, $2 in USDC.

## The entry

> I have x-ray vision, but only through glass, and only when the glass is clean.

## How it works

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes the
line above to `/output/entry.txt`. `OUTPUT_DIR` overrides the output
directory for local testing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
